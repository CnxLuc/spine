Spine

A calm reading layer for long writing. Open it on any article with ⌥⇧S or the toolbar button.

Who reads

An AI reads each article once: it picks the key sentences, writes a short note for each section and a line for each fold. Spine saves the notes in this browser, so opening an article again is free.

Manage usage
Use Claude Code or Codex? Run this once in Terminal to connect Spine to them: curl -fsSL https://cnxluc.github.io/spine/connect.sh | bash

Spine uses your own Anthropic API credits

Claude’s reading is billed by Anthropic to the API account your key belongs to, at Anthropic’s prices. API credits are bought separately from a Claude.ai Pro or Max subscription; to read on a subscription, use ChatGPT or Claude Code above.

First time with the Claude API?
  1. Sign up at platform.claude.com, with the same email as Claude.ai if you like. The API account is separate.
  2. Add credit under Billing. $5 covers about 8 long essays or 80 short posts with Opus 5.5. You can set a monthly spend limit there too.
  3. Create a key under API keys, paste it above and select Test.
