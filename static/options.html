Spine

A calm reading layer for long writing. Open it on any article with ⌥⇧S or the toolbar button.

Claude

Claude reads each article once: it picks the key sentences, writes a short note for each section and a line for each fold. Spine saves the notes in this browser, so opening an article again is free.

Spine uses your own Anthropic API credits

Spine is free. Claude’s reading is billed by Anthropic to the API account your key belongs to, at Anthropic’s prices. A Claude.ai Pro or Max subscription can’t pay for it: API credits are bought separately.

First time with the Claude API?
  1. Sign up at platform.claude.com, with the same email as Claude.ai if you like. The API account is separate.
  2. Add credit under Billing. $5 covers about 8 long essays or 80 short posts with Opus 5.5. You can set a monthly spend limit there too.
  3. Create a key under API keys, paste it above and select Test.
